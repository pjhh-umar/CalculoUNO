Definición

Sean \(a,b\in\mathbb{R}\). Se define la diferencia de \(a\) y \(b\), denotada por \(a-b\), mediante

\[ a-b:=a+(-b), \]

donde \(-b\) es el inverso aditivo de \(b\). Si además \(b\neq 0\), se define el cociente de \(a\) entre \(b\), denotado por \(\displaystyle \frac{a}{b}\), mediante

\[ \frac{a}{b}:=a\cdot b^{-1}, \]

donde \(b^{-1}\) es el inverso multiplicativo de \(b\).

Definición

Sea \(a\in\mathbb{R}\) y sea \(n\) un número natural con \(n\geq 1\). La potencia de base \(a\) y exponente \(n\), denotada por \(a^n\), se define como el producto de \(n\) factores iguales a \(a\):

\[ a^n:=\underbrace{a\cdot a\cdots a}_{n\text{ factores}}. \]

En particular, \(a^1=a\). Si \(a\neq 0\), se definen además las potencias de exponente cero y de exponente entero negativo como

\[ a^0:=1, \qquad a^{-n}:=(a^{-1})^n=\frac{1}{a^n}, \quad n\geq 1. \]

Definición

A partir del conjunto \(\mathbb{R}_{+}\) de los axiomas de orden, se establecen las siguientes definiciones y notaciones. Sean \(x,y\in\mathbb{R}\).

  1. Se escribe \(x > y\), y se lee «\(x\) es mayor que \(y\)», si \(x-y\in\mathbb{R}_{+}\). Es decir, \[ x > y \quad\Longleftrightarrow\quad x-y\in\mathbb{R}_{+}. \]
  2. Se escribe \(x < y\), y se lee «\(x\) es menor que \(y\)», si \(y-x\in\mathbb{R}_{+}\). Es decir, \[ x < y \quad\Longleftrightarrow\quad y-x\in\mathbb{R}_{+}. \] Las desigualdades escritas con los signos \(<\) y \(>\) se llaman desigualdades estrictas.
  3. Se dice que un número real \(x\) es positivo si \(x\in\mathbb{R}_{+}\) , es decir, si \(x > 0\).
  4. Se dice que un número real \(x\) es negativo si \(-x\in\mathbb{R}_{+}\), es decir, si \(x < 0\).
  5. Se escribe \(x\geq y\), y se lee «\(x\) es mayor o igual que \(y\)», si \(x > y\) o \(x=y\). Es decir, \[ x\geq y \quad\Longleftrightarrow\quad x > y\ \text{o}\ x=y. \]
  6. Se escribe \(x\leq y\), y se lee «\(x\) es menor o igual que \(y\)», si \(x < y\) o \(x=y\). Es decir, \[ x\leq y \quad\Longleftrightarrow\quad x < y\ \text{o}\ x=y. \]
  7. Se dice que un número real \(x\) es no negativo si \(x\geq 0\), es decir, si \(x > 0\) o \(x=0\).
  8. Se dice que un número real \(x\) es no positivo si \(x\leq 0\), es decir, si \(x < 0\) o \(x=0\).

Observación

El número \(0\) es no negativo y no positivo, pues \(0\geq 0\) y \(0\leq 0\). Sin embargo, no es positivo ni negativo. En particular,

\[ 0\notin\mathbb{R}^{+}, \qquad 0\notin\mathbb{R}^{-}. \]

Notación

Para \(a,b,c\in\mathbb{R}\), se utiliza la siguiente notación abreviada para expresar que dos desigualdades se cumplen simultáneamente:

\[ a < b < c \quad\Longleftrightarrow\quad a < b\ \text{y}\ b < c, \] \[ a\leq b\leq c \quad\Longleftrightarrow\quad a\leq b\ \text{y}\ b\leq c, \] \[ a\leq b < c \quad\Longleftrightarrow\quad a\leq b\ \text{y}\ b < c, \] \[ a < b\leq c \quad\Longleftrightarrow\quad a < b\ \text{y}\ b\leq c. \]

Las cadenas con \(>\) o \(\geq\) se interpretan de manera análoga.

Principio de inducción matemática

Sea \(P(n)\) una afirmación que depende de un número natural \(n\geq 1\). Para demostrar mediante el principio de inducción matemática que \(P(n)\) es verdadera para todo número natural \(n\geq 1\), se procede de la siguiente manera:

  1. Caso base: se demuestra que \(P(1)\) es verdadera; es decir, se verifica la afirmación para \(n=1\).
  2. Hipótesis de inducción: se toma un número natural \(k\geq 1\) arbitrario y se supone que \(P(k)\) es verdadera. Esta suposición se utiliza para demostrar el paso siguiente.
  3. Paso inductivo: bajo la hipótesis de inducción, se demuestra que \(P(k+1)\) también es verdadera; es decir, se prueba la afirmación para el siguiente número natural.

Una vez verificado el caso base y demostrado el paso inductivo, el principio de inducción matemática permite concluir que \(P(n)\) es verdadera para todo número natural \(n\geq 1\).

Observación

El caso base puede corresponder a un valor distinto de \(n=1\), según el rango para el cual se desea demostrar la afirmación. Por ejemplo, para demostrar que \(P(n)\) es verdadera para todo número natural \(n\geq 2\), se procede así:

  1. Caso base: se demuestra que \(P(2)\) es verdadera.
  2. Hipótesis de inducción: se toma un número natural \(k\geq 2\) arbitrario y se supone que \(P(k)\) es verdadera.
  3. Paso inductivo: bajo esta suposición, se demuestra que \(P(k+1)\) también es verdadera.

Se concluye que \(P(n)\) es verdadera para todo número natural \(n\geq 2\). Si también se desea incluir el caso \(n=1\), este debe comprobarse por separado.

En general, si se comienza en un número natural \(n_0\), se verifica \(P(n_0)\) y se demuestra el paso inductivo para un número natural arbitrario \(k\geq n_0\). La conclusión será válida para todos los números naturales \(n\geq n_0\).
